- **Judge Rationale:** Tests scalability considerations and performance bottlenecks.
- **Winning Answer:**
  > *"Our watcher utilizes native VS Code file system watchers and incremental debounced document scans. Rather than re-parsing the entire workspace on every keystroke, the engine:
  > 1. Restricts full scans strictly to workspace activation and project manifest changes (`requirements.txt`, `package.json`).
  > 2. Processes incremental diffs on save events for active documents.
